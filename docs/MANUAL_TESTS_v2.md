# BodgeGene — Полный чеклист ручного тестирования v2

**Версия:** v0.2.3-alpha  
**Дата:** 30 марта 2026  
**Покрытие:** Весь функционал React Designer + Backend API  
**Формат:** ☐ → ☑ при прохождении. Каждый тест самостоятельный.

**Предусловия:**
- Frontend: `cd gui/designer && npm run dev` → localhost:3000
- Backend: `cd gui/api && py -m uvicorn server:app --port 8000 --reload`
- Браузер: Chrome/Edge (для DevTools)
