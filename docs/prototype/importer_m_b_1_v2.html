Modal · Dedup prompt при resourceHash collision.
  • Триггерится на финальный Confirm — `checkLibraryDedup(resourceHash)` нашёл existing entry.

  • В multi-file mode dedup проверяется per-file, prompt появляется на каждый collision файл (sequential).

Modal · Primer wizard step (DEC-LIB-08 / DEC-IMP-11 ⚓).
  • Триггерится только при .dna с primer_bind features где есть `sequence`. Для .gb / .fasta без primer metadata — модалка не показывается.
  • Default: все checked. Дубль (resourceHash совпадает с existing primer в Library) — checkbox unchecked + warning row + tooltip «Уже в Library».
  • Критичная нота: footnote в body явно говорит «только в Library, не в project pool» — биолог понимает разницу между «банк олигов» (Library) и «заказанные для текущего проекта» (project primer pool, M-F).
