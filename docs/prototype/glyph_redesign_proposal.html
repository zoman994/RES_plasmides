Glyph library redesign — визуальная система

Фундамент: stroke #3A2F1F единый для всех глифов · fill из feature-palette.js по type/name через featureColor() · 3 уровня плотности · единый baseline для backbone-глифов на y=22 · stroke-width 2 в координатах viewBox 36×36.

1. Принципы

Один stroke на всю библиотеку

Все глифы рисуются warm-dark-brown #3A2F1F. Тот же тон, что обводка regions в PlasmidMap → визуальная сцепка между глифом, аннотацией и картой.

Fill из feature-palette

Цвет заливки — производная от type/name через featureColor(). CDS жёлто-зелёный, promoter жёлтый, terminator оранжевый. Биологическая type-coding читается мгновенно.

Три уровня плотности

Не 12 произвольных fillOpacity от 0.08 до 0.40. Solid (1.0), accent (0.55), outline-only (none). Глаз привыкает к шкале, перестаёт «читать» как разный визуальный вес.

Backbone-baseline y=22 у всех

Глифы с DNA-линией (RBS, operator, primer_bind, restriction, intron, MCS, ncRNA) — все с backbone на y=22 в viewBox 36×36. На линейной карте выстраиваются в одну линию.

2. Шкала плотности

Каждый глиф попадает в одну из трёх корзин. Никаких произвольных значений между.

6. Архитектурный сдвиг — связка с feature-palette

Самое важное технически. Сейчас глиф не знает свой цвет — он принимает color параметром. Предложение: новый wrapper SBOLIcon читает цвет из палитры по type/name.

// sbol-glyphs.jsx — новая обёртка
import { featureColor, FEATURE_STROKE } from './feature-palette';

export function SBOLIcon({ type, name, size = 18, density = 'auto' }) {
  const Comp = GLYPH_MAP[type] || GLYPH_MAP[GLYPH_ALIASES[type]] || MiscGlyph;
  const fill = featureColor(type, name);          // из палитры
  const stroke = FEATURE_STROKE;                  // #3A2F1F всегда
  const fillOpacity = resolveDensity(density, type);  // 1.0 / 0.55 / 0
  return <Comp size={size} stroke={stroke} fill={fill} fillOpacity={fillOpacity} />;
}

Каждый глиф-компонент принимает теперь четыре параметра: size, stroke, fill, fillOpacity. Никаких color='currentColor', никаких color='#000'. Default density='auto' читает из реестра «этот глиф из какой корзины» (solid / accent / outline-only). При желании можно явно переопределить.
