Modal · Dedup prompt при resourceHash collision.
  • Триггерится на финальный Confirm — `checkLibraryDedup(resourceHash)` нашёл существующий entry.
  • Body: показывает existing entry (name + meta + теги) — биолог сразу видит что у него уже есть.
  • 3 кнопки: Заменить (primary) — старая entry overwrites, теги старой merge в новую; Добавить оба — два entries с одинаковым resourceHash; Пропустить (subtle) — abort, ничего не сохраняется.
  • В multi-file mode dedup проверяется per-file, prompt появляется на каждый collision файл.
  • DEC-IMP-10 — explicit prompt не silent overwrite (биолог не знает о потере tags).

Modal · Primer wizard step (DEC-LIB-08 / DEC-IMP-11 ⚓).
  • Триггерится только при .dna с primer_bind features где есть `sequence`. Для .gb / .fasta без primer metadata — модалка не показывается.
  • Default: все checked (биолог явно снимает что не нужно). Дубль (resourceHash совпадает с existing primer в Library) — checkbox unchecked + warning row + tooltip «Уже в Library» (open Q3 §10 спеки).
  • Per-row: name (редактируемое inline?) + sequence в моноширинном + Tm/length + direction tag.
  • Footer: «Skip» (продолжить без primers, primers пропускаются) или «+ Add N в Library» (где N = checked count).
  • Критичная нота: footnote в body явно говорит «только в Library, не в project pool» — биолог понимает разницу между «банк олигов» (Library) и «заказанные для текущего проекта» (project primer pool, M-F).
