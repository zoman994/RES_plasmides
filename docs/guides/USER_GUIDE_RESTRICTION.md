# BodgeGene — Работа с сайтами рестрикции

Справочник для пользователей. Версия 0.4.0, апрель 2026.

---

## Как увидеть сайты рестрикции на карте плазмиды

Откройте плазмиду (двойной клик или из каталога). На панели инструментов нажмите кнопку "RE sites" — на круговой карте появятся отметки сайтов рестрикции.

Цвет отметки показывает, сколько раз фермент режет в данной плазмиде:

- Красная длинная чёрточка — фермент режет ОДИН раз (unique cutter). Подписан именем.
- Оранжевая средняя — режет 2 раза (double cutter).
- Серая короткая — режет 3+ раз.

Если программа обнаружила MCS (Multiple Cloning Site — область с высокой плотностью unique сайтов), она подсветит его фиолетовой дугой.

### Фильтры

По умолчанию показаны только unique cutters с сайтом 6+ п.н. — обычно это 8-20 ферментов, карта не перегружена. Фильтры:

- "1×" — только unique cutters (по умолчанию, самый полезный для клонирования)
- "≤2×" — unique + double cutters
- "All" — все найденные сайты

### Информация по клику

Клик на отметку RE-сайта открывает карточку:
- Название фермента и позиция разреза
- Последовательность распознавания с указанием точки разреза
- Тип концов: 5' overhang, 3' overhang или тупые
- Буфер и температура
- Совместимые ферменты (с таким же overhang)
- Предупреждение о Dam/Dcm чувствительности (если есть)

При наведении (без клика) — быстрый tooltip с основной информацией.

## Рестрикционное клонирование (Фаза 2)

Классическая операция: взять вектор, разрезать рестриктазами, вставить ген.

### Как это работает

1. Откройте плазмиду-вектор (например, pUC19 из каталога)
2. В меню операций выберите "Рестрикционное клонирование"
3. Выберите один или два фермента для разреза. Программа покажет:
   - Что именно вырезается (подсвечено на карте)
   - Размер backbone и вырезанного фрагмента
   - Совместимость буферов для двойного разреза
4. Выберите вставку — ген из библиотеки или вставьте последовательность
5. Программа проверит:
   - Совместимость концов (overhangs match?)
   - Нет ли внутренних сайтов выбранных RE в вашей вставке
   - Сохранение рамки считывания (для CDS)
   - Предложит альтернативы если что-то не так
6. Результат появляется на canvas как два фрагмента: backbone + insert
7. Праймеры для вставки генерируются автоматически (с RE-тейлами)

### Направленная vs ненаправленная вставка

Два разных фермента (например, EcoRI + BamHI) = направленная вставка. Вставка может войти только в одной ориентации. Рекомендуется.

Один фермент (например, только EcoRI) = ненаправленная. Вставка может войти в любой ориентации. Программа предупредит и предложит дефосфорилировать вектор.

### Совместимые ферменты

Некоторые ферменты дают одинаковые overhangs, хотя распознают разные сайты:

- BamHI и BglII — оба дают 5' GATC
- XhoI и SalI — оба дают 5' TCGA
- EcoRI и MfeI — оба дают 5' AATT
- XbaI, NheI, SpeI — все дают 5' CTAG

Это полезно: если ваша вставка содержит BamHI-сайт (и будет разрезана), используйте BglII — тот же overhang, но другой сайт распознавания. После лигирования junction не режется ни BamHI, ни BglII.

### Защитные нуклеотиды на праймерах

RE-ферменты плохо режут на самом конце ДНК. Программа автоматически добавляет 2-6 защитных нуклеотидов перед RE-сайтом на праймере. Количество зависит от фермента (данные NEB).

## Шпаргалка

| Я хочу... | Как |
|---|---|
| Увидеть RE-сайты | Кнопка "RE sites" на карте плазмиды |
| Найти unique cutters в MCS | Фильтр "1×", MCS подсвечен фиолетовым |
| Узнать детали фермента | Клик на отметку RE-сайта |
| Вставить ген в вектор | Операция "Рестрикционное клонирование" |
| Проверить совместимость RE | Клик → карточка → "Compatible" |
| Найти альтернативный RE | Программа предложит при конфликте внутренних сайтов |
