# BodgeGene — Как работают аннотации и операции

Справочник для пользователей. Версия 0.4.0, апрель 2026.

---

## Как работать с фрагментами: правый клик

Все операции над фрагментом доступны через правый клик мыши. Меню зависит от типа фрагмента — BodgeGene показывает только те действия, которые имеют смысл.

### CDS, ген, маркер — самое богатое меню

Правый клик по белок-кодирующему фрагменту:

- **Точечная мутация** — открывает последовательность белка. Кликните по аминокислоте, выберите замену из предложенных (Ala scan, изостерные, charge swap) или введите свою. Один клик — одна мутация — новая версия.
- **Мутагенез (wizard)** — для сложных случаев: несколько мутаций одновременно, делеции, инсерции. Программа сама выберет стратегию: KLD для близких мутаций, overlap PCR для далёких.
- **Добавить тег/fusion** — пресеты: His6, FLAG, Strep-II, V5 (C-terminal) или MBP, GST, SUMO (N-terminal fusion). С сайтами протеолиза: TEV, Thrombin. И линкерами: (G₄S)×3.
- **Заменить** — открывает библиотеку частей, отфильтрованную по типу. Выбрали другой CDS → старый заменён, праймеры пересчитаны.
- **Разрезать** — разделить фрагмент на две части (для вставки кассеты, создания homology arms).
- **Перевернуть (RC)** — reverse complement. Горячая клавиша: R.
- **Сохранить в библиотеку** — если фрагмент с мутациями или модификациями, сохранить как новый Part.

### Промоторы и терминаторы

Меню проще — мутагенез белка здесь не нужен:

- **Заменить** — свап на другой промотор или терминатор из библиотеки. BodgeGene фильтрует список по типу: промотор → только промоторы.
- **Перевернуть** — если промотор в неправильной ориентации.
- **Редактировать** — изменить последовательность вручную.

### Плазмида (импортированная, circular)

Если вы перетащили плазмиду из библиотеки, BodgeGene предложит набор плазмидных операций:

- **Заменить кассету** — выбрать экспрессионную или селекционную кассету → заменить целиком на новую.
- **Мутировать ген** — выбрать CDS из списка регионов плазмиды → точечная мутация или wizard.
- **Вставить элемент** — выбрать позицию между регионами → вставить loxP, NLS, новый ген.
- **Удалить регион** — нокаут: выбрать ген → удалить → новая версия (Δ).
- **Дерево версий** — вся история этой плазмиды: кто от кого произошёл, какие мутации.
- **Разобрать на части** — все регионы плазмиды → отдельные Parts в библиотеке.

### Стык между фрагментами

Клик по вертикальной линии между двумя фрагментами открывает настройки стыка:

- **Тип**: Overlap / Golden Gate / RE-лигирование / KLD — выбирается для каждого стыка отдельно.
- **Параметры**: длина overlap, целевая Tm, направление (◀ / ◀▶ / ▶), фермент GG, рестриктаза.

Вам не нужно выбирать "метод сборки" для всего конструкта. Каждый стык независим. Можно смешивать: два стыка overlap, один Golden Gate, один RE — BodgeGene рассчитает праймеры для каждого.

## Что происходит, когда вы добавляете элемент

Вы перетащили последовательность на canvas. Что BodgeGene сделал за вас — и зачем.

### CDS, ген, маркер — белок-кодирующие элементы

Программа транслирует последовательность в белок и ищет в нём знакомые структуры:

- **Сигнальный пептид** — гидрофобный N-концевой участок (метод von Heijne, порог >0.5). Если нашёлся — значит, белок секретируемый, и вы это увидите розовой секцией на блоке.
- **Пропептид** — участок после SP до дибазического сайта KR/KK. Встречается у секретируемых протеаз (pepA, glaA).
- **Теги** — His6, FLAG, Strep-II, V5, Myc, HA, GST, MBP, SUMO. Ищутся по точному совпадению аминокислотного паттерна.
- **Сайты протеолиза** — TEV, Thrombin, PreScission, Enterokinase, Factor Xa.
- **Линкеры** — участки, богатые S/T/P/G (>60% в окне 15 а.о., длина 10–50 а.о.).
- **Стартовый и стоп-кодоны** — ATG и TAA/TAG/TGA.

Координаты всех этих элементов **привязаны к нуклеотидам**, но в подсказках вы увидите и аминокислотные позиции: `Signal peptide: 1–22 а.о. (1–66 п.н.)`.

На canvas-блоке будет цветная полоска: сигнальный пептид розовым, каталитический домен голубым, линкер серым, тег жёлтым. В SequenceViewer можно переключиться между ДНК, белком и картой деталей.

### Промоторы

Здесь белка нет, программа ищет регуляторные элементы в нуклеотидной последовательности:

- **TATA box** — TATAA[AT][AG], в последних 50 п.н. промотора.
- **CAAT box** — CCAAT, на расстоянии 50–120 п.н. от конца.
- **−10 и −35 элементы** (прокариоты) — TATAAT и TTGACA с допуском до 2 мисматчей.
- **RBS** (прокариоты) — Shine-Dalgarno, AGGAGG.

Прокариот или эукариот — определяется по организму. Если организм не указан, программа ищет и то, и другое.

### Терминаторы

- **Poly-A сигнал** — AATAAA.

### Все типы

По всей последовательности ищутся **сайты рестрикции** 16 распространённых ферментов. Они видны как точечные метки.

### Enrichment — узнавание известных элементов

После автоаннотации BodgeGene проверяет последовательность по базе из 96 известных генетических элементов. Если гомология >80% — регион получает имя из базы. Так вы видите «PglaA» вместо безымянного «promoter».

## Три уровня аннотаций

**Регион** — что эта ДНК собой представляет. CDS, промотор, терминатор, origin of replication.

**Деталь** — структурный элемент внутри региона. Сигнальный пептид внутри CDS, TATA box внутри промотора.

**Точка** — маркер конкретной позиции. Сайт рестрикции, стартовый кодон, мутация.

В редакторе аннотаций это дерево: регионы раскрываются, показывая свои детали и точки.

## Импорт плазмиды

Загружаете .dna (SnapGene) или .gb (GenBank) файл. Три этапа:

1. **Парсинг features** — каждый feature из файла → region-аннотация.
2. **Автоаннотация деталей** — SP, теги, линкеры для CDS. TATA, CAAT для промоторов. Poly-A для терминаторов.
3. **Enrichment** — проверка по базе. Безымянные features получают имена.

Программа автоматически определяет **кассеты** (промотор → CDS → терминатор). На кольцевой карте кассеты видны как дуги.

## Мутагенез

### Точечная мутация (через контекстное меню)

Правый клик по CDS → «Точечная мутация» → кликните по аминокислоте D908 → выберите A → готово.

BodgeGene создаст версию v1.1, скопирует все аннотации, добавит point «D908A». Координаты не сдвинутся.

### Несколько мутаций (через wizard)

Правый клик по CDS → «Мутагенез (wizard)» → добавьте D908A, E993A, L1200V → Compute Strategy.

Программа выбирает стратегию: KLD для близких, multi-fragment overlap для далёких. Все мутации — отдельные точечные аннотации.

### Мутации в разных генах

Мутируете сначала XynTL (D908A), потом pyrG (K15R). Каждая мутация привязана к своему региону. Semantic diff: «D908A в XynTL, K15R в pyrG».

### Мутация + делеция

D908A + удаление линкера. Длина меняется → CDS укорачивается → downstream сдвигается автоматически.

## Замены

### Замена одного элемента

Правый клик → «Заменить» → библиотека, фильтрованная по типу → выбрали → готово.

Старый элемент и его аннотации удалены. Новый вставлен с autoAnnotate. Downstream сдвинуты на разницу длин. Версия v2.0.

### Замена кассеты

Правый клик по плазмиде → «Заменить кассету» → выбрать expression → подставить PcbhI+BGL1+TcbhI.

Все регионы старой кассеты удалены, новые добавлены, downstream сдвинуты. Версия v2.0.

---

## Добавить тег или fusion

Правый клик по CDS → «Добавить тег/fusion...»

Пресеты:

| Тег | Позиция | Длина | Назначение |
|---|---|---|---|
| His6 | C-term | 18 п.н. | Очистка на Ni-NTA |
| FLAG | C-term | 24 п.н. | Иммунодетекция |
| Strep-II | C-term | 24 п.н. | Очистка на Strep-Tactin |
| V5 | C-term | 42 п.н. | Детекция |
| MBP | N-term | ~1100 п.н. | Растворимость (fusion) |
| GST | N-term | ~690 п.н. | Растворимость (fusion) |
| SUMO | N-term | ~300 п.н. | Растворимость (fusion) |
| TEV site | Линкер | 21 п.н. | Между fusion и белком |
| (G₄S)×3 | Линкер | 45 п.н. | Гибкий линкер |

Выбрали тег + позицию → BodgeGene вставит последовательность, расширит CDS-регион, добавит деталь-аннотацию, сдвинет downstream. Малые теги (His6, FLAG) — версия v1.1. Крупные fusion (MBP, GST) — версия v2.0.

## Стыки между фрагментами

Каждый стык настраивается независимо. Кликните по вертикальной линии между блоками.

**Overlap / Gibson** — стандартный метод. Настраивается: длина overlap (15–60 п.н.), направление (на левый / оба / правый праймер), расчёт по длине или по Tm.

**Golden Gate** — для множества фрагментов. Выбираете фермент (BsaI, BpiI, BsmBI...), программа предлагает 4-нуклеотидные overhang-и из последовательности. Проверяет палиндромы, дубликаты, RC-конфликты.

**RE-лигирование** — классика. Рестрикция обоих фрагментов + лигирование. Поиск фермента по имени, сайту или overhang-у. Предупреждение, если сайт есть внутри фрагмента.

**KLD** — для мутагенеза. Back-to-back праймеры, фосфорилирование + лигирование + DpnI.

Можно смешивать: два стыка overlap, один Golden Gate. BodgeGene рассчитает праймеры для каждого типа.

## Делеции

### Удаление региона

Правый клик по плазмиде → «Удалить регион» → выбрать pyrG → подтвердить.

Регион и его детали удалены. Downstream сдвинуты. Версия v2.0. Плазмида получает имя «ΔpyrG».

### Удаление домена из белка

Через FragmentEditor: выделить участок → удалить. CDS укорачивается. Деталь удалена. Downstream сдвинуты.

### Удаление интронов

Через FragmentEditor: программа находит интроны (GT...AG), предлагает удалить. Каждый удаляется от конца к началу. CDS укорачивается. Стоп-кодоны внутри интронов исчезают.

---

## Flip (reverse complement)

Кнопка ↻ на hover-панели или клавиша R. Последовательность переворачивается, координаты аннотаций зеркалятся, autoAnnotate пересчитывается.

---

## Версии

**Minor (v1.1, v1.2...)**: точечная замена, добавление малого тега.

**Major (v2.0, v3.0...)**: делеция, крупная вставка, замена элемента, замена кассеты, flip.

В дереве версий (🌳, через контекстное меню плазмиды) — вся история с семантическим описанием: «D908A в XynTL» вместо «1 nucleotide change».

## Ручные аннотации

Кнопка «+ Добавить аннотацию» в AnnotationEditor. Укажите имя, тип и координаты. Программа определит уровень автоматически. Ручные аннотации сохраняются при пересчёте.

## Шпаргалка: правый клик

| Я хочу... | Правый клик → |
|---|---|
| Мутировать аминокислоту | CDS → «Точечная мутация» |
| Несколько мутаций | CDS → «Мутагенез (wizard)» |
| Добавить His-tag | CDS → «Добавить тег/fusion» → His6 → C-term |
| Заменить промотор | Промотор → «Заменить» → выбрать из библиотеки |
| Заменить ген | CDS → «Заменить» → выбрать из библиотеки |
| Заменить кассету | Плазмида → «Заменить кассету» |
| Удалить ген | Плазмида → «Удалить регион» → выбрать |
| Вставить loxP | Плазмида → «Вставить элемент» |
| Посмотреть историю | Плазмида → «Дерево версий» |
| Настроить стык | Клик по линии между блоками |
| Перевернуть | Любой фрагмент → «Перевернуть (RC)» или R |
