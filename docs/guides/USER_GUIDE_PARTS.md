# BodgeGene — Управление библиотекой элементов

Справочник для пользователей. Версия 0.4.0, апрель 2026.

---

## Библиотека: что это и как она работает

В BodgeGene все ваши генетические элементы хранятся в одной библиотеке. Промоторы, гены, терминаторы, маркеры, целые плазмиды — всё здесь. Библиотека общая для всех проектов: элемент, созданный в одном проекте, доступен в другом.

Каждый элемент в библиотеке имеет статус, который отражает его реальное положение — существует он только на экране или уже лежит в морозилке.

---

## Два статуса: запланирован и получен

### Запланирован (жёлтый бейдж)

Элемент существует только в компьютере. Вы спроектировали мутант, спланировали сборку, нарисовали конструкт — но в лабе его ещё нет.

Такой статус получают:
- Мутанты, которые вы создали через мутагенез
- Результаты сборки (после "Complete assembly", но до секвенирования)
- Промежуточные фрагменты (split, fusion)
- Последовательности, введённые вручную

Запланированные элементы видны в палитре всегда, но группируются по проектам: элементы текущего проекта показаны вверху, элементы других проектов — в свёрнутой секции внизу. Ничего не спрятано — только приоритизировано.

### Получен (зелёный бейдж)

Элемент существует физически. Вы его получили, секвенировали, подтвердили — он лежит в пробирке.

Такой статус получают:
- Элементы из импортированных файлов (.dna, .gb) — файл = чья-то проверенная работа
- Стандартные элементы из базы (PglaA, pyrG...)
- Любой элемент после нажатия "Mark as verified"

Полученные элементы видны везде, во всех проектах. Это ваш рабочий фонд — плазмиды в морозилке, из которых можно вырезать кассеты и строить новые конструкты.

### Когда элемент из "запланированного" становится "полученным"?

Это момент, когда in silico дизайн превращается в пробирку. Типичный путь:

1. Вы спроектировали мутант XynTL(D908A) → **запланирован**
2. Собрали плазмиду pGAP-XynTL-D908A → **запланирован**
3. Трансформировали, получили колонии, отправили на секвенирование
4. Секвенирование подтвердило 100% совпадение
5. Правый клик на плазмиде → "Mark as verified" → **получен**
6. Теперь pGAP-XynTL-D908A доступна во всех проектах как шаблон

Если вы используете планировщик (Project Flow), переход происходит ещё проще: когда все проверки (colony PCR, секвенирование) отмечены как пройденные, программа сама предложит: "Сборка прошла все проверки. Отметить как полученную?"

## Архив

Элемент можно архивировать — он исчезнет из палитры, но не будет удалён. Полезно для:

- Старых промежуточных фрагментов, которые больше не нужны
- Неудачных вариантов мутантов
- Элементов из удалённого проекта

Восстановить из архива: фильтр "Показать архив" → правый клик → "Restore".

---

## Что происходит при удалении проекта

Программа спросит: "В проекте есть запланированные элементы. Архивировать?"

- **Запланированные** (мутанты, промежуточные фрагменты) → уходят в архив
- **Полученные** (плазмиды, которые вы реально получили) → остаются в библиотеке

Это логично: удаление проекта = удаление рабочего процесса. Но пробирки в морозилке не исчезают вместе с заметками.

---

## Палитра: что вы видите

Палитра показывает ВСЕ элементы, кроме архивных, но группирует их по релевантности:

- **Этот проект** (раскрыт) — запланированные элементы текущего проекта
- **Библиотека** (раскрыт, по категориям) — все полученные элементы
- **Другие проекты** (свёрнут) — запланированные элементы из других проектов
- **Инвентарь** (свёрнут) — амплифицированные продукты

Ничего не спрятано. Поиск ищет везде — во всех секциях одновременно.

---

## Как это работает с планировщиком

Планировщик (Project Flow, Ctrl+5) — визуальная схема вашего проекта: от шаблонов через ПЦР к сборке и проверке.

Элементы на схеме отражают свой статус:
- Шаблонные плазмиды (зелёная рамка) — **получены**, из морозилки
- Product сборки (жёлтая рамка) — **запланирован**, ещё не в лабе
- После прохождения всех checkpoint-ов → программа предложит отметить как полученный

Это не обязательный путь. Вы можете не использовать планировщик вообще — статус меняется из палитры или контекстного меню.

---

## Инвентарь

Инвентарь — отдельное понятие от статуса. Элемент с пометкой "получен" означает, что он реально существует. Инвентарь хранит детали: номер пробирки, позиция в морозилке, концентрация, объём.

Один элемент может иметь несколько записей в инвентаре — если есть аликвоты или glycerol stock.

---

## Именование продуктов сборки

При завершении сборки программа предлагает имя: "Проект 1 — Сборка 3". Вы можете переименовать. Если элемент с таким именем уже существует — программа предупредит и предложит уточнить название.

## Краткая шпаргалка

| Я хочу... | Как |
|---|---|
| Импортировать плазмиду из файла | Drag .dna файл → статус "получен" автоматически |
| Создать мутант | Правый клик на CDS → Мутагенез → статус "запланирован" |
| Собрать конструкт | Canvas → Complete Assembly → статус "запланирован" |
| Подтвердить после секвенирования | Правый клик → "Mark as verified" |
| Использовать плазмиду в другом проекте | Она уже видна (если "получена") → Drag на canvas |
| Скрыть старые черновики | Правый клик → "Archive" |
| Найти элемент из другого проекта | Поиск → показывает все статусы |
| Удалить проект | Запланированные → в архив, Полученные → остаются |
