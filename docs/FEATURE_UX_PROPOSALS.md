## 1. Перспектива молбиолога (что важно на стенде)

Игорь — грибная биотехнология (ФИЦ Биотех РАН). Реальный пользователь фич — это:

1. **Мышечная память SnapGene.** Биолог 10 лет смотрит на плазмиду с CDS-золотой, промотор-зелёный, ori-серый, RE-тики снаружи. Любое отклонение от этого мысленного шаблона = трение. Конвенция цветов и «одно кольцо, фичи-стрелки» — не наша свобода, а ожидание.
2. **Скорость разметки.** На стенде размечают десятки конструктов. «Выделил → назвал → Enter» должно быть мгновенным. Многополевой диалог на каждую фичу = боль (универсальная во всех 5 ПО).
3. **Корректность координат и рамки.** 1-based на экране (биолог думает «нуклеотид 146»), strand явный, рамка считывания видна. Ошибка в рамке/координате = испорченный эксперимент.
4. **Саб-фичи реальны и важны.** Белковая инженерия = домены внутри CDS (каталитический, сигнальный пептид, таги, линкеры). **Грибные гены = интроны** (это detail внутри гена!). Биологу нужно ВИДЕТЬ их на карте, а не только в текстовом списке.
5. **Доверие к авто-аннотации.** «Откуда этот хит? Полный он или обрезок?» — без провенанса и fragment-флага биолог не доверяет авто-разметке (ключевой урок pLannotate).
6. **Последствие правки сразу.** Поменял基у в CDS → silent? missense? frameshift? Биолог должен видеть мгновенно, а не вычислять в уме.

## 3. Предложения улучшений (ранжировано: ценность молбиологу × усилие)

### P0 — высокая ценность, чинит реальную боль (берём первыми)

**UX-1. Саб-фичи и точки видимы на картах (B1, V-FEAT-3).**
Кольцевая/линейная карта рендерит `detail` как тонкие вложенные дуги/полоски ВНУТРИ родительского region (как SnapGene/Geneious), `point` (RE-сайт/мутация/старт-стоп) как радиальные тики. **Для грибных генов — exon-блоки:** ген с интронами рисуется сегментированной дугой (интрон = разрыв), как pLannotate. Реализация: `PlasmidMapV2`/`LinearMapV2` читают `getDetails`/`getPoints` (не только `getRegions`); вложенный слой на радиусе `fOut+δ`. Усилие: среднее. Ценность: высокая (особенно Игорю).

**UX-2. Двусторонняя подсветка фичи карта↔сиквенс (B2, V181).**
`selectedRegionId` пробрасывается в `AnnotationTrack`; строка фичи подсвечивается при `region.id === selectedRegionId` (учесть legacy-без-id через `matchesAnnotationId`). Клик по фиче в сиквенсе → `onSelectRegion`. Двусторонне, как все 5 ПО. Усилие: низкое-среднее. Ценность: высокая (базовая ожидаемость).

**UX-3. Каскад regionId при правке (B3, V180) — фикс-трек.**
(Уже в плане фиксов.) Правка координат/имени/типа региона не сиротит саб-фичи. TDD-первым. Усилие: низкое. Ценность: критическая (тихая потеря данных).

### P1 — сильные дифференциаторы

**UX-4. Fragment-aware рендеринг неполных фич (B4, pLannotate-差別化).**
Фича с покрытием <95% референса (обрезок после рестрикции, `_part_`) рисуется белой заливкой + цветной контур на ВСЕХ поверхностях → глаз читает «неполная». У нас уже есть `_part_`/`mergeStripWithPredicted` — связать с визуалом + hover «обрезок N% от AmpR». Усилие: среднее. Ценность: высокая (доверие, уникально среди десктоп-ПО).

**UX-5. Быстрое создание фичи с клавиатуры (B5).**
Выделил диапазон → `F` (или `N`) → инлайн-поле имени → тип авто-угадывается (ORF→CDS) или быстрый дропдаун → Enter. Без модалки для частого случая (модалка — только для тонкой правки). Ни у кого из 5 ПО нет — реальный leapfrog, и идеально ложится на «принцип двух кликов» BodgeGene. Усилие: среднее. Ценность: высокая (скорость стенда).

**UX-6. Protein Effect badge при правке CDS (B7, Geneious-差別化).**
При изменении баз внутри CDS — мгновенный бейдж на сиквенсе: `silent ✓` / `missense (A→T)` / `frameshift ⚠` / `truncation ⚠` / `extension`. У нас есть AA-трек + `sequence-diff.aaChange` — собрать в badge. Громкий тост на frameshift (универсально слабое место всех ПО). Усилие: среднее. Ценность: высокая (предотвращает ошибки).

**UX-7. Provenance + fragment в авто-аннотации (B6, pLannotate).**
Hover на авто-фиче: источник (common-features/ORF/PWM), %покрытия, %идентичности, fragment-флаг. Неполные — отдельно помечены. Усилие: низкое-среднее. Ценность: средняя-высокая (доверие).

### P2 — полировка консистентности

**UX-8. Единый оттенок цвета + accessibility-палитра (B8, V-FEAT-4, ApE).**
Чипы редактора → `featureColorShaded` (как карты): один ген — один цвет везде. Палитра с luminance-границами для контраста ≥3:1 (ApE Palette Generator — единственная accessibility-aware среди 5 ПО). Усилие: низкое. Ценность: средняя.

**UX-9. Sub-feature редактор первого класса (B1, белковая инженерия).**
Выделил под-диапазон внутри CDS → «вложить как домен/таг/интрон в <ген>» (2 клика) → создаётся `detail` с `regionId`. Сейчас только split на N равных. Усилие: среднее. Ценность: средняя (белковики, грибные интроны).

**UX-10. Единый hover-tooltip фичи (Geneious/pLannotate).**
Имя · тип · координаты 1-based · strand · длина · (для CDS) AA-длина + рамка. Одинаковый на всех поверхностях. Усилие: низкое. Ценность: средняя.

**UX-11. Консолидация affordance правки (B9).**
Один воркфлоу правки фичи (drag-края + dbl-click→редактор) одинаков в Library/Align/Canvas; Annotator остаётся для accept/reject авто-хитов. Усилие: среднее. Ценность: средняя.

## 4. Что уже хорошо (НЕ ломать)

- 3-уровневая модель `region>detail>point` в одном `annotations[]` — чище, чем `domains[]` у legacy-ПО.
- 0-based half-open в store + 1-based на UI через `toUiCoords` — корректная биология.
- Plasmid-Git (версии/ветки) — **нет прямых аналогов** (UX_REFERENCE_BASE Workflow 9): inline-diff с AA-эффектом был бы уникален.
- Авто-аннотация с предсказателями (ORF/PWM/stem-loop/sgRNA) + accept/reject — на уровне Annotator-флоу хороших ПО.
- Drag-края фич в сиквенсе — есть (Benchling-уровень прямой манипуляции).

## 5. Дорожная карта UX-трека (в лупе)

1. **P0** первыми: UX-3 (V180 фикс) → UX-1 (саб-фичи на картах = V-FEAT-3) → UX-2 (sync выделения = V181). Эти три закрывают и баги, и главные UX-боли.
2. **P1**: UX-4 (fragment-визуал) → UX-6 (Protein Effect badge) → UX-5 (быстрое создание).
3. **P2**: цвет/тултип/консолидация по остаточному времени.
4. Каждый шаг — TDD-первым + браузер-верификация на реальной молекуле (грибной ген с интроном — хороший тест-кейс).
