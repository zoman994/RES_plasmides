## Тест 1: Quick Start — первый экран

**Цель:** Проверить что новый пользователь видит понятную стартовую страницу.

**Шаги:**
1. После очистки localStorage должен появиться QuickStart с 7 кнопками
2. **Скриншот №1:** Стартовый экран

**Что проверить:**
- [ ] 7 кнопок видны (restriction, gibson, GG, mutagenesis, catalog, import, free)
- [ ] Лого "🧬 BodgeGene" сверху
- [ ] Подсказка "или перетащите файл в окно" внизу
- [ ] Палитра слева видна (должна быть пустая или с fallback данными)

## Тест 2: Restriction Cloning — полный workflow

**Цель:** Импорт плазмиды → restriction cloning wizard → canvas с праймерами.

### Шаг 2a: Импорт файла
1. Перетащи файл `scripts/snapgene_dna/basic_cloning_vectors/pAN7-1.dna` в окно браузера
2. Должен появиться ImportDecisionModal
3. **Скриншот №2:** ImportDecisionModal с информацией о pAN7-1

**Что проверить:**
- [ ] Имя файла показано
- [ ] Длина в п.н. показана
- [ ] Topology: circular
- [ ] Кнопки: Клонировать / Как backbone / Мутагенез / Просмотреть / В библиотеку / Разобрать

### Шаг 2b: Просмотр плазмиды
1. Нажми "👁 Просмотреть"
2. Должен открыться PlasmidViewer с круговой картой
3. **Скриншот №3:** PlasmidViewer — круговая карта pAN7-1

**Что проверить:**
- [ ] Круговая карта с цветными секторами (features)
- [ ] Таблица аннотаций справа
- [ ] Кнопки в footer: "🔪 Клонировать", "⚗️ Как backbone", "🔄 Мутагенез" (если Блок 9 выполнен)
- [ ] Последовательность внизу с цветной подсветкой регионов

### Шаг 2c: Restriction cloning wizard
1. Закрой PlasmidViewer
2. Найди pAN7-1 в палитке слева → drag на canvas (или открой через контекстное меню)
3. В PlasmidUseWizard выбери "🔪 Рестрикционное клонирование"
4. **Скриншот №4:** Wizard шаг 1 — выбор ферментов

**Что проверить:**
- [ ] Список unique cutters отображается
- [ ] Можно выбрать два фермента
- [ ] При выборе — позиции подсвечиваются на карте
- [ ] checkDoubleDigest warnings (если есть)

### Шаг 2d: Выбор insert
1. Выбери два фермента (например, те что есть как unique cutters)
2. Нажми "Далее"
3. На шаге 2: выбери "Вставить последовательность" 
4. Введи имя: "TestGene", последовательность: `ATGAAAGCATTCATCGGTCTGGCCGCAGCTGGTATTGCATCG` (любая)
5. **Скриншот №5:** Wizard шаг 2 — insert

### Шаг 2e: Preview + создание на canvas
1. Нажми "Далее" → Preview
2. **Скриншот №6:** Wizard шаг 3 — preview
3. Нажми "🔪 Создать на canvas"
4. **Скриншот №7:** Canvas с 2 фрагментами + ligation junctions + праймеры

**Что проверить на canvas:**
- [ ] 2 фрагмента видны (backbone + insert)
- [ ] Junction показывает тип "ligation" (🔪 или красный)
- [ ] Праймеры рассчитаны автоматически
- [ ] ActionBar видна (✅ N пар праймеров + кнопки)

## Тест 3: Gibson Assembly

**Цель:** Собрать конструкт из нескольких фрагментов через палитру.

### Шаг 3a: Подготовка
1. Нажми "Clear" (очистить canvas)
2. Если QuickStart не появился → обнови страницу (Ctrl+R)
3. Нажми "⚗️ Gibson / Overlap сборка"
4. **Скриншот №8:** Состояние после выбора Gibson (hint или пустой canvas)

**Что проверить:**
- [ ] Видна подсказка "Перетащите запчасти из палитры" (если Блок 9 выполнен)
- [ ] Кнопка "+ Добавить фрагмент по последовательности" (если Блок 9 выполнен)
- [ ] Кнопка "← Назад к выбору метода"

### Шаг 3b: Добавить фрагменты
1. Если в палитке есть pAN7-1 (из теста 2) → перетащи на canvas
2. Перетащи ещё один элемент из палитки (или добавь через "+" → paste sequence)
3. **Скриншот №9:** Canvas с 2+ фрагментами

**Что проверить:**
- [ ] Блоки фрагментов видны с правильными цветами
- [ ] Junctions между ними (overlap по умолчанию)
- [ ] Zoom/fit работает
- [ ] Можно кликнуть junction → настроить

### Шаг 3c: Праймеры и ActionBar
1. Если ≥2 фрагментов с последовательностями → праймеры автоматически
2. **Скриншот №10:** ActionBar + праймеры

**Что проверить:**
- [ ] ActionBar: "✅ N пар праймеров" + кнопки
- [ ] Tabs: Последовательность / Праймеры / Протокол / Статистика
- [ ] Клик "📋 Протокол" → вкладка Protocol
