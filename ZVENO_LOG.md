# ZVENO_LOG.md — лог звеньев BodgeGene

> **Что это.** Журнал фиксов, сделанных методом «Звено» (`CHAT_PLAYBOOK.md`,
> раздел «Режимы работы»). Звено = один сломанный шаг: прочитан код →
> инструкция Code в диалоге → принято в живом приложении.
>
> **Зачем файл.** Замкнутое звено иначе нигде не отслеживается — фикс
> теряется между сессиями. Это НЕ накопительный трекер задач (звенья не
> копятся по построению), а лог уже сделанного — для регрессии и истории.
>
> **Формат.** Одна строка на звено: проблема → решение → статус. Кратко.
> Нумерация `Z<N>` — отдельная от `V<N>` багов `BUGS.md`. Звено, которому
> присвоен V-номер в `BUGS.md`, дублируется сюда строкой со ссылкой.
>
> **Гигиена.** Закрытые звенья старше ~2 сессий — в `docs/archive/`
> (как BUGS.md FIXED). Не давать файлу разрастаться.
