## P1 — executeCut не отклоняет конфликт одного DSB

`gui/designer/src/components/CanvasSkeleton/canvas/operations/adapters/cut.js:50-55`
использует canonical `digest()` только для circular template и не более двух ферментов.
Линейный template и circular с тремя или более ферментами идут через ветку `:114-128`,
которая сортирует occurrences только по `topCut` и не сравнивает полный
`restrictionBreakKey`.

Контрпример:

```text
sequence = GGGACGTTACCC
IsoA = { site: ACGTTA, cut: [1,4] } -> topCut 4, bottomCut 7
NeoB = { site: ACGTTA, cut: [1,3] } -> topCut 4, bottomCut 6
```

Один физический DSB не может одновременно иметь два bottom-cut. Текущий adapter создаёт
две границы на topCut 4; нулевой средний фрагмент затем фильтруется, а соседние продукты
получают несовместимые ends вместо fail-closed ошибки.

Conflict proof существует для `digestCircular` и `digestFragments`, но не проходит через
production `executeCut`. Сам `cut.js` изменён ASM-5B и входит в его owned manifest, поэтому
это blocker текущего product-кандидата, а не соседний legacy-долг.
